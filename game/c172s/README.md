# 《C172S 五边飞行》(C172S Pattern Flight)

一个**从零用 6502 汇编写的原创 NES 游戏**(NROM,mapper 0,32KB PRG + 8KB CHR):
[C172S Simulator](https://github.com/bigcubedata/test/tree/claude/goal-setting-sjhs9v)
(Godot 版塞斯纳 172S 训练模拟器)的红白机原生移植——
**座舱内第一人称视角 + 真实空气动力学**,理念照搬(POH 目标数字 +
起落航线逐段教官评分),表现形式全是 1985 年的做法。

仓库直接附带构建好的 `c172s.nes`:

```sh
cargo run --release -p nes-frontend -- game/c172s/c172s.nes --scale 4
```

## 座舱视角(Top Gun 式,但是塞斯纳)

- **风挡**(上半屏):全景地平线随**真实航向**横向卷动(512px 全景 =
  两张 nametable 拼 360°),地平线随俯仰上下移动;远山/云随转弯掠过;
  五边上能看到**透视跑道**由远及近变大,旁边是 **PAPI 四灯**
  (两白两红 = 在下滑道上)。
- **仪表盘**(下半屏):sprite-0 分屏固定,真**六联表**——空速表、
  姿态仪(地平杆随俯仰/坡度动)、高度表(双针)、转速表、航向表、
  升降速度表,全部精灵指针;右侧数字区 IAS/ALT/VS/HDG/RPM/襟翼/配平;
  失速警告红灯、航段目标与 A-E 评分、教官消息行、小地图机位点。

## 真实气动(`tools/gen_aero.py` 生成,整数孪生过 POH 校验)

不是查表手感,是真公式发射成 6502 查找表:

| 物理 | 实现 | 校验结果 |
|---|---|---|
| 升力 | L = qS·CL,CL(α,襟翼) 线性到 CLmax 后失速跌落 | 失速 48/46/44/41 KIAS(襟翼 0/10/20/30) |
| 诱导阻力 | k·CL²(k=1/πeAR),**地效 ×0.55** | 拉平时明显飘飞,掉速软着陆 |
| 功率曲线 | T = min(静推力, η(V)·P/V),180 BHP 定距桨 | Vy≈74 KIAS/约 700 fpm;满油门平飞 123 |
| 能量交换 | dV/dt = g(T−D)/W − g·sinγ | 拉杆掉速、俯冲增速;背功率曲线区存在 |
| 转弯 | dψ/dt = g·tanφ/V;需求升力 ×1/cosφ | 30° 坡度失速速度 +7%;转弯不带杆会掉高掉速 |
| 滑翔 | 收油门加风车桨阻力 | 最佳滑翔比 ≈10:1 |
| **风** | 定常风 300°/8kt + LFSR 阵风(±25%,低空垂直扰动) | 五边要压偏流,拉平自动蹬正后漂移渐起 → 别飘太久 |
| **P-factor** | 大功率低速左偏(0.3-0.7°/s) | 滑跑/爬升要"踩右舵"(地面 ←→ 转向),教官会喊 RIGHT RUDDER |
| **定距桨** | RPM = f(油门, 空速) + 一阶惯性 | 满油门静止 ~2300,滑跑中涨到 ~2600;俯冲怠速风车增速;声调跟随 |
| **电动襟翼** | 1 档 ≈1.4s 渐变 + 电机声 | Vfe:>85 kt 放襟翼警告扣分 |
| **失速深化** | 迎角超临界 + 坡度>8° → 掉翼(坡度发散) | base-final 低速转弯失速会真的甩坡度;抖振画面震动 |
| **着陆动力学** | 400-700 fpm 接地 → 真实弹跳(能量回弹),三连跳 = 海豚跳 | 前轮先着(θ<1°)降档;侧向漂移 >20 判侧载 |

姿态(俯仰配平)是玩家的主控:**带杆改速度、油门改下滑道**——
教科书进近技术在这台"红白机"上是真的成立的。侧风着陆的取舍也是真的:
蟹形进近保持中线,拉平自动蹬正后侧向漂移开始累积,飘得越久侧载越大。

## 玩法(左起落航线,真实转弯)

| 航段 | 目标 |
|---|---|
| 起飞滑跑 | 全油门,55 抬轮(需要真实的迎角裕度才离地) |
| 一边 | Vy **74** 爬升 |
| 二边 | 继续爬向 **1000** ft |
| 三边 | 平飞 1000 ft,**90** KT;中点收油放襟翼 |
| 四边 | 襟翼 20°,**73** KT 下降 |
| 五边 | 襟翼 30°,**65** KT,盯 PAPI 两白两红,压中线 |
| 拉平 | 收油带住,地效里飘到掉速接地(<150 fpm = A) |

到转弯点教官喊 "TURN LEFT!"——**压住左坡度真转 90°**,滚出对准
新航向;直线段还得随时用浅坡度修掉 P-factor 与风致偏航(AI 演示也在
这么做)。错过窗口教官代打并扣分。塔台全程有电台:报三边、许可着陆,
**第一圈五边 200 ft 有 1/4 概率被塔台喊复飞**——3 秒内满油门收襟翼
+300 分,无视塔台照落重罚。着陆按下沉率 + 中线 + 接地姿态 + 侧向
漂移评分,弹跳会真的弹起来。落完看 FLIGHT LOG:六项评分 + **你真实
飞出的航迹图**(和理想矩形一比就现形)。

**完好落地后 START 续飞进阶:白天 → 黄昏 → 夜航**(总分累计)。
夜航整个世界只剩跑道白边线和 PAPI,仪表盘换红光夜照——真·仪表进近。
标题等 13 秒,自动驾驶(姿态飞行法 + 直线段航向保持 + 正切收油程序)
自己飞整圈演示,循环播放。

## 键位

| 键 | 功能 |
|---|---|
| ↑ / ↓ | 俯仰配平(按住连续,7.5°/s) |
| ← / → | 压坡度(按住滚转,松手回平,最大 30°) |
| A / B | 油门 +/-(按住连发) |
| SELECT | 襟翼 0/10/20/30° |
| START | 开始 / 暂停 |
| B(滑跑) | 刹车 |

失速警告按**迎角**触发(和真飞机一样是 AoA 传感,不是速度)。

## 视觉/声音层(全部 1985 年做法)

- 失速抖振/接地冲击的**全机身震动**(风挡 X 抖 + 面板分屏 Y 抖);
- 地面**双相调色板行进**(节奏 ∝ 地速,每次只写 2 个调色板字节)+
  滑跑时**中线虚线向脚下涌**(贴块相位替换);
- **低空地面扑面**:<150/<50 ft 地面纹理两级变粗,拉平的"地面涌上来"
  是真实的高度知觉线索;
- **跑道侧偏透视**:偏离中线时梯形真的歪(顶行全偏/中行半偏),
  对中不再只靠 HDG 数字;
- 空速表**绿弧/白弧 + Vne 红线**(独立调色板格),姿态仪**天蓝/藏青
  真地平面**(上半透明借全局天色,夜航自动变黑);
- 压坡度时两侧精灵云反向升降(外景滚转暗示);油门旋钮在仪表台滑槽上
  随档位移动;调色板 4 步淡入淡出转场;
- 引擎方波音调跟随**真实转速**(含惯性与风车效应),襟翼电机嗡声,
  电台呼叫带沙沙声,接地闷响 + 噪声爆发。

## 构建

```sh
sudo apt install cc65
./build.sh   # gen_aero.py 气动表 + gen_chr.py 图块 → ca65 → ld65
```

- `tools/gen_aero.py` — 浮点气动模型(校验 POH)→ 发射整数查找表
  `src/aero_tables.inc`,内置 60Hz 整数孪生仿真复算失速/爬升/极速/
  滑翔比/坡度失速,校验不过不发射。
- `tools/gen_chr.py` — 程序化 CHR:ASCII 对齐字库、全景地平线图块、
  透视跑道、仪表圈、16 向指针(5 图块 + 翻转)、姿态仪地平杆、PAPI。
- `src/c172s.s` — 游戏本体(~2600 行 ca65):SMB 式全 NMI 主循环、
  sprite-0 分屏 + hblank 内 4 写切面板、全景卷动、动态地平线行重写、
  跑道贴块流式擦画、整数气动管线(带符号 8×8 乘法/算术移位)、
  真实航向/位置导航的航线状态机、姿态飞行法自动驾驶。

回归:`cargo test -p nes-core c172s`。
