# 《比武大会》GRAND TOURNEY —— 骑士长枪比武(NES 原创)

从零用 6502 汇编写的原创 NES 游戏(NROM,32KB PRG + 8KB CHR,构建好的
`tourney.nes` 已入库)。中世纪马上长枪比武(jousting):《Punch-Out!!》式
读招对决 + **把骑士精神写进规则**——荣誉不是剧情,是系统。

```sh
cargo run --release -p nes-frontend -- game/tourney/tourney.nes --scale 4
```

## 玩法

两骑沿栅栏(tilt)对冲。冲锋中:

| 键 | 功能 |
|---|---|
| **B 按住** | 举盾护**盔**(松开护**胸**)——盾位对手全程可见,这是他读你的牌 |
| **A + 上** | 固枪刺**盔**(2 分,对方护盔则断枪于盾 1 分) |
| **A**(无方向) | 固枪刺**胸/盾**(1 分) |
| **A + 下** | **低刺**——不设防、重创座力,但**失德**(见下) |
| 预备期按 **B** | 向观众致意(+荣誉,有礼的对手会回礼) |

**固枪时机**是核心手感:接近到 160px 内才能固枪;
- **太早**(>56px):出枪清楚,但银鸢/铁伯爵/冠军会**看破你的枪线换盾**;
- **贴身**(24–56px):**完美一击**(附加座力伤,精灵闪光);
- **过迟**(<24px):擦枪(减半)。
沉住气到最后一刻才放平枪——这本身就是骑士课。

**座力(SEAT)**:每骑一条平衡槽。盔击 6、胸击 4、盾挡 2、低刺 8,完美 +2、
擦枪减半;归零即**坠马**,当场分胜负。三回合定胜负,平局加赛至五回合,
再平由**裁判按荣誉裁决**。

## 荣誉系统(骑士精神即规则)

| 行为 | 荣誉 |
|---|---|
| 预备期致意观众 | +3(有礼对手回礼) |
| 对手**断了盾带**那回合收枪不刺(全场欢呼 "COURTESY!") | +6 |
| 坠马胜后**扶起对手**(A:AYE / B:NAY) | +5 |
| 干净击败低刺者黑棘(全场自己没用低刺) | +10 |
| 胜一场 | +2 |
| 击打无盾之人 | −4 |
| **低刺**(观众嘘声、裁判警告;再犯**取消资格**判负) | −8 |
| **低刺致坠 = 击马犯规**,当场取消资格(历史真规则) | 判负 |

荣誉的用处:平局裁决偏向高荣誉者;**决赛失利时荣誉 ≥60 观众会为你要来
再战一场**;结局三分支(≥60 真骑士加冕 / 常规 / <20 空冠——荣誉过低时
你的蓝袍会当场褪成黑色)。低刺不是不给用——是给你一条随时可选的捷径,
和一面全场看得见的镜子。

## 声画

单屏无卷轴(不需要分屏),画面按魂斗罗的密度标准做:

- **场景分层**:远景城堡雉堞剪影、飘旗绳每 32 帧换相摆动、后排暗
  人群 + 两排头肩人潮、条纹华盖王座包厢(帷幔/流苏/栏杆)、割草带
  与草丛花点、沙地"远亮近暗"五段景深(亮带/耙纹/蹄痕翻沙带)、
  tilt 栅栏受光缘 + 投影线。
- **战马四相旋转跑**(腾空前伸/前蹄落地/收拢/后蹄蹬地,身体随步态
  沉浮),弓颈深胸、鬃尾流线、鞍毯肚带全描边。
- **打击反馈**:交锋点 16×16 三帧爆裂(白芯→尖刺环→火花),受击方
  全身白闪 + 后仰姿态帧;打盔震屏 6 帧、坠马震屏 16 帧(滚动抖动);
  断枪四屑抛物弧四散;冲锋蹄下连续扬尘;完美固枪枪尖拖速度线。
- **观众演出**:大欢呼时看台两行起立举臂再坐下(nametable 行重写);
  荣誉三角旗行、欢呼/嘘声音量包络同步。
- **黄昏决赛**:战役后两战与隔轮演示换黄昏调色板——橙天、暗红人潮、
  burnt 沙地,决赛的仪式感。汉字标题浮雕化(上左受光/下右暗缘)。

马蹄噪声随速度、断枪噪声爆发、盔击金属高频、致意小号、号角冲锋令;
标题纹章号角二重奏。坠马者翻滚扬尘,空马自己跑完全程;盔缨被击飞。
对手罩袍颜色逐场变化(调色板动态改写)。

## 构建

```sh
sh game/tourney/build.sh   # 需要 cc65(ca65/ld65)与 python3
```

`tools/gen_chr.py` 程序化生成全部图块(字库/竞技场/战马两帧奔跑/骑士/
「比武大会」汉字标题,画布+矩形+自动描边,无手打长串)。冒烟测试:
`cargo test -p nes-core tourney`。
