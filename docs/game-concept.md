# 《守誓人》游戏概念设计书

> The Oathkeeper —— 一款以儒家君子之德重铸骑士精神的中世纪游侠骑士游戏

## 一、立意

骑士文学里的 knight-errant，中文恰译作"游侠骑士"——仗剑行游，路见不平。
这与儒家的君子几乎是同一种人：有所为，有所不为；重然诺，轻生死；
达则兼济天下，穷则独善其身。

本作的核心命题不变：**把德行做成持续运转的玩法系统，而不是对话选项。**
中世纪骑士守则（Chivalry）讲勇武、公正、慈悲、慷慨、忠信、谦礼——
本作用五常为骨架将其重铸：玩家不是"扮演"一个骑士，而是在一次次
比武、决斗、赎俘、守诺与无人看见的抉择中，"行"出一个君子骑士。

## 二、世界观：裂而未崩的王国

架空中世纪。老王驾崩，无嗣，三家摄政各执一方玉玺残片，王国裂而未崩：
律法还在，却无人执行；道路还通，却盗匪横行；骑士团还在，却各事其主。

乱世正是试金石。玩家是一名刚受封的贫穷骑士——无封地、无家名、
一马一剑一纸誓词。天下失序之时，一个人的操守还算数吗？
这是游戏要玩家用行动回答的问题。

时代质感取十二至十四世纪：链甲与初期板甲、比武大会、纹章学、
赎俘惯例、假释誓约（parole）。不加魔法——在失序的世界里守住誓言，
本身就是传奇。

## 三、五常玩法：德行即机制

### 仁 —— 剑下留人
- 决斗与战场采用**降伏系统**：压制对手气势与体势后，可迫其
  缴械、坠马或口称"降"（yield）。杀与不杀，永远是玩家的一念。
- 中世纪惯例：被俘骑士可**赎俘**。收赎金是正当的；但你也可以
  分文不取放人归去。
- **铁律：不杀降者，不伤马匹，不掠平民。** 违者声望永久刻痕，
  某些人物终生不再与你同席。
- 被你放走的人回到世界里：有人传扬你的名声，有人来投效，
  也有人再度提剑相向——仁慈有真实的回响，也有真实的风险。

### 义 —— 路见不平
- 行游途中随机遭遇：被劫的商队、被恶领主逼租的村庄、雪夜里
  求援的信使。拔剑相助意味着**误掉比武报名、得罪当地权贵、
  空掉钱袋**。
- 义举没有任务奖励结算画面。回报以人情、传闻、危难时的援手
  等世界回响的方式，在很久之后到来。
- **慷慨（Largesse）**是骑士古德，也是义的延伸：比武赢得的
  赎金与骏马，散给寡妇、老兵与随从，还是攒起来买更好的甲？
  钱袋是这个游戏最诚实的德行计。

### 礼 —— 纹章与仪节
- 比武大会有全套古礼：报名亮纹章、向观礼席致敬、选择"钝枪"
  （礼斗）或"利枪"（生死斗）、胜后向败者执礼。
- 礼是这个世界的外交语言：对宿敌依礼下战书，可以把一场伏杀
  变成堂堂正正的决斗；在异国宫廷失仪，可能让整条行游路线
  对你关门。
- 纹章系统：玩家的纹章由自己的行迹"长"出来——世界根据你的
  作为授予纹章要素与称号，你的盾面就是你的履历。

### 智 —— 读人与择战
- 决斗采用**架势与破绽**系统：三种架势相互克制，佯攻、后发、
  耗其体势。蛮力连挥必败，读懂对手才能赢——比武是武艺，
  更是心智。
- 战前情报与择战：打听对手的惯用手、检查场地泥泞、评估自己
  的伤势。"君子不立于危墙之下"——知道哪场比武不该上场，
  与知道怎么赢同样是智。
- 乱局中的判断：有些"求救"是陷阱，有些"恶人"另有隐情。
  义要以智行之，游戏会奖励先查证再拔剑的玩家。

### 信 —— 一诺千金
- 玩家立下的每个誓言与承诺（比武之约、护送之诺、假释誓约、
  对垂死者的一句"我会转告"）都记入**誓约簿**。
- **假释誓约**是中世纪真实惯例，也是本作的招牌机制：你放走的
  俘虏若立誓不再与你为敌，多数人会守誓——因为你守誓。
  你毁诺一次，此后所有人的誓言对你都开始失效。
- 守诺积累"信望"：铁匠赊账、领主托孤、素不相识者以性命相托。
  毁诺不掉血不扣钱，但世界会慢慢对你关门。

### 慎独 —— 无人看见的骑士
- 部分抉择发生在**无人知晓**处：深林里没有目击者的决斗、
  可以私吞的失主财物、无人核对的比武战绩。
- 游戏对"有人看见的德行"与"无人看见的德行"分别记账。
  慎独之行从不带来声望，却决定真结局——"君子慎其独也"。

## 四、核心循环

1. **在城镇/营地**：听风闻（世界回响）、接诺、修甲养马、
   打探对手、报名比武。
2. **在路上**：行游遭遇（义举、伏击、礼节场合、隐情事件）。
3. **在比武场/决斗场**：马上长枪对冲 + 步战决斗，胜负之外
   永远有"如何胜"的抉择。
4. **在世界**：你的每次选择化作传闻、纹章、敌友与门户开阖，
   改变后续行游路上的世界。

一段行游约 15–25 分钟，章节式叙事战役（王国存亡主线）+
可重复的比武巡回赛。

## 五、玩家体验目标

- **决斗手感**：易上手、难精通的架势博弈，胜负三五分钟内见
  分晓，但每一场都可复盘。
- **德行的重量感**：行五常短期总是吃亏的（君子固穷），但世界
  的长期回响让玩家由衷觉得"值得"。
- **结局不评分、不发奖杯**：终章只让你看见——这个裂而未崩的
  王国，因你成了什么样子；你的盾面纹章，就是你的一生。

## 六、美术与声音基调

- 视觉：手绘挂毯/泥金抄本风格（类《贝叶挂毯》线条 × 中世纪
  细密画配色），庄重而不写实血腥。
- 文字：叙述旁白庄重简净，誓词与战书用半文半白，点出士人
  气质与骑士文书的双重古意。
- 音乐：中世纪调式（里拉琴、手摇风琴、颂歌）与古琴、箫的
  对话；决斗中音乐渐隐，只余呼吸、甲叶与钢声。

## 七、技术方案（分期）

| 阶段 | 内容 | 技术 |
|------|------|------|
| P0 原型 | 步战决斗架势系统 + 降伏/杀俘抉择 + 一场比武大会 | HTML5 Canvas / TypeScript，浏览器即开即玩 |
| P1 纵深 | 马上长枪对冲、行游地图与遭遇、誓约簿与信望、3–4 章战役 | 同上 + 存档、事件脚本系统 |
| P2 扩展 | 纹章生成系统、比武巡回赛、慎独真结局 | 视反响决定 |

选择 Web 技术栈：零安装、跨平台、便于快速迭代与分享试玩，
适合本仓库直接开发。

## 八、待与作者商定的问题

1. **视角**：2D 侧视决斗（剑斗表现力强）还是俯视行游 + 侧视
   决斗的双视角？
2. **飞行情结**：是否加入"鹰隼骑士团"之类的空中骑兵设定
   （狮鹫/巨鹰坐骑），把您的飞行员理想融进中世纪世界？
   还是保持无魔法的写实中世纪？
3. **名称**：《守誓人》为暂定名，备选《不坠之誓》《君子之盾》。
